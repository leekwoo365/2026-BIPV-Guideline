# 04. 시뮬레이션 방법론

## 도구
- Rhino + Grasshopper, Ladybug Tools(1.9.0), Honeybee.
- 분석 자동화: grasshopper-mcp / Swiftlet MCP 연동 가능.

## 1) 일사량 / 발전량
- 입력: EPW 기상데이터(`data/`), 모듈 효율·면적.
- 출력: 입면별 연간 일사량(kWh/m²), 예상 발전량.
- 메쉬 포인트별 일사량 → 모듈 배치 우선순위 도출.

## 2) 자연채광 (Daylight)
- 지표: sDA, ASE, DF 등.
- 목적: BIPV 입면이 실내 채광에 주는 영향 평가(투과형 모듈 시).

## 3) 빛반사 / Glare
- 반사광 추적: 모듈 표면 정반사 방향 → 주변 수광면(도로·건물) 도달 여부.
- 시간대·계절별 태양 위치 스윕으로 민감 시간 식별.
- 층별(저/중/고) 분류로 반사 위험 차등 평가 — SKB 구로 BIPV 최적화 패턴.

## 결과 관리
- 원본 수치/이미지: `simulation/`, `assets/images/`에 보관.
- 보고서(`reports/`)에는 인용만, 출처(파일·파라미터) 명시.

## 검증 원칙
- 가정(반사율·기상연도·메쉬 해상도) 명시. 수치는 단정 전 근거 확인.
