# 01. 프로젝트 개요

## 배경
- 제로에너지건축물(ZEB) 인증 의무화 확대에 따라 BIPV 적용 수요 증가.
- 입면 활용형 BIPV는 채광·빛반사(glare)·미관·발전효율의 상충 관계를 동시에 고려해야 함.

## 목적
1. 2026년 기준 BIPV 설계·검토에 바로 쓸 수 있는 실무 가이드라인 정립.
2. 법규 → 설계기준 → 시뮬레이션 → 사례 → 보고서로 이어지는 일관된 워크플로우 제공.

## 산출물
- 가이드라인 본문 (docs/ 통합)
- 시뮬레이션 템플릿 (Rhino/GH)
- 체크리스트 및 보고서 양식 (reports/)

## 대상 독자
- 설계 실무자, 친환경/에너지 검토 담당, 시공·인증 협의 담당.

## 범위 경계
- 포함: 입면·지붕 일체형 모듈, 채광/빛반사/일사 검토.
- 제외: 발전 사업성(LCOE) 상세 재무모델 — 별도 검토.
