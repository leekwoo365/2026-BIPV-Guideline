## 1. 제로에너지건축물(ZEB) 의무화 — 핵심 (D6)
- **시행**: 2025년 6월 30일부터 **민간** 건축물로 확대 의무화 (당초 2023년 초 예정 → 자재비·분양가 우려로 약 1년 6개월 유예 후 시행).
- **대상**:
  - 민간 **공동주택 30세대 이상**
  - 민간 **일반건축물 연면적 1,000㎡ 이상**
  - (공공은 2020년 1,000㎡↑ → 2023년 500㎡↑ 선행 의무화)
- **수준**: **ZEB 5등급**(에너지자립률 **20~40%**) 수준 설계 의무.
- **강화 항목**: 창호 태양열취득, 거실 조명밀도, 고효율 냉·난방설비 등 **8개 항목** + **신재생에너지 설비 설치 의무**.
- **향후**: **2030년 연면적 500㎡ 이상**까지 민간 의무 확대 예정. 등급 기준도 단계적 상향(4등급↑) 추진.

> **BIPV 함의**: 옥상 태양광만으로 자립률 충족이 어려운 고층·고밀 건물일수록 **입면 BIPV가 필수**.
> 민간 의무화로 BIPV 적용 대상이 공공에서 **민간 오피스·공동주택**으로 급격히 확대됨 → 2026 가이드라인의 핵심 동인.

### ZEB 등급 체계 (참고)
| 등급 | 에너지자립률 |
|------|--------------|
| 1등급 | 100% 이상 |
| 2등급 | 80~100% |
| 3등급 | 60~80% |
| 4등급 | 40~60% |
| 5등급 | 20~40% |

## 2. 신재생에너지 설치의무화 (공공) · 설치기준
- **상위법**: 「신에너지 및 재생에너지 개발·이용·보급 촉진법」 제12조.
- **공공기관 신재생 공급의무비율**: 연도별 상향(예상에너지사용량 대비). 공공건축물은 2030년 기준 비율까지 단계 상승.
- **설치 기준(지원지침)**: 모듈 일조면은 원칙적으로 **정남향**, 불가 시 동/서 **45°(공급인증 대상 60°) 이내**.
  단, 기존 건축물 지붕·벽체와 평행하게 BAPV/BIPV 설치 시 **동/서 90° 이내** 허용.
  일조시간 **1일 5시간 이상**(춘계 3~5월·추계 9~11월 기준).

## 3. 지자체 녹색건축물 설계기준 (조례)
- 서울특별시·인천시 등은 신재생에너지 규모별 설치비율(대지면적 계수)·태양광 설치용량(kWp) 의무 규정.
- **2026 확인 필요**: 2022년판이 인용한 서울 2019·인천 2021 기준은 **개정 가능성** → 최신 조례본 대조 후 갱신(`references/`).

## 4. BIPV 제품·시공 인증 (KS) — 갱신
- **KS C 8577 「건물일체형 태양광 모듈(BIPV) — 성능평가 요구사항」**: BIPV 전용 표준(2016.12.28 제정).
  - **최근 개정**(11/17): 기술 발전에 따라 **설치 위치·적용 재료 범위 확대** 반영.
  - 인증: 한국에너지공단(KNREC) 위탁 시험기관(예: KTC) 인증.
- 일반 결정질/박막 모듈 안전·성능: KS C 8561/8562 등 병행.
- 구조(풍하중·적설)·방화(준불연 이상)·전기(감전·아크) 안전 기준 적합 필요.

## 5. 상위 정책 · 인접 법규 (2026 신규 반영)
- **탄소중립기본법**(기후위기 대응을 위한 탄소중립·녹색성장 기본법): 건물 부문 온실가스 감축 목표 → ZEB·BIPV 추진 동력. (D7 탄소·경제성과 직결)
- **인공조명에 의한 빛공해 방지법**: BIPV 입면 반사광 민원 리스크 → **빛반사 정량 검토(04) 필요성 강화**. (D3 연계)
- **RE100 / 재생에너지 사용**: 민간 기업 사옥의 자가발전 수요 → BIPV 채택 유인.
