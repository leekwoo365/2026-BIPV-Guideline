# 🌞 BIPV 설계 가이드라인

## 0. 기획·구상 (Pre-Design)
### ✓ 체크사항
- BIPV 적용 목표 (제로에너지 등급 / 신재생 의무비율)
- 적용 대상 부위 후보 (지붕 · 입면 · 차양 · 난간)
- 법규 적용대상 여부 (용도·규모·지자체 조례)
- 예산 · 인센티브 · 보조금 가능성
- 개략 발전량 / 자립률 목표
### ▶ 설계자 액션
- 적용 목표·범위 설정 (발주처 합의)
- 적용 부위 우선순위 정의
- 개략 시스템 용량 가설정
### ◎ 협력 전문가
- 친환경(에너지) 컨설턴트
- 전기(신재생) 엔지니어
- 발주처 / 인허가 담당

## 1. 계획설계 (SD)
### ✓ 체크사항
- 매스 · 향 · 경사 · 음영 분석
- 적용 부위 결정 (입면 vs 지붕 vs 차양)
- 외피 통합 디자인 (색상·패턴·투과율)
- 빛반사(glare) 민원 리스크
- 일조·조망 등 주변 영향
### ▶ 설계자 액션
- BIPV 적용 부위 배치 확정
- 향·경사 발전 최적화 검토
- 모듈 색상/패턴 디자인 방향 설정
- 개략 빛반사 검토 의뢰
### ◎ 협력 전문가
- 태양광 전문업체 (모듈)
- 빛반사·일사 시뮬레이션
- 도시계획 (일조·조망 심의)

## 2. 기본설계 (DD)
### ✓ 체크사항
- 모듈 선정 (타입 · 효율 · KS 인증)
- 발전량 시뮬레이션 (PVsyst 등)
- 구조 정착 방식 · 하중
- 전기 결선 · 인버터 · 계통연계
- 방화 · 이격 · 안전 기준
### ▶ 설계자 액션
- 모듈 사양 확정
- 시스템 용량 산정
- 부착 디테일 협의
- 채광·빛반사·일사 정밀 시뮬레이션 의뢰
### ◎ 협력 전문가
- 구조 엔지니어
- 전기 엔지니어
- 태양광 제조사
- 인증기관

## 3. 실시설계 (CD)
### ✓ 체크사항
- 상세도 · 시방서 작성
- KS · 인증 · 성능 서류
- 방수 · 단열 · 외피 연계 디테일
- 안전 (감전 · 화재 · 낙하)
- 유지보수 접근성
### ▶ 설계자 액션
- 도서 작성 · 시방 반영
- 수량 산출 · 적산 연계
- 인허가 / 인증 서류 준비
### ◎ 협력 전문가
- 적산 / 견적
- 감리
- 인증기관 · 시공사

## 4. 시공·감리 / 운영 (CA · O&M)
### ✓ 체크사항
- 설치 검측 · 시공 품질
- 발전 성능 검증 · 시운전
- 모니터링 체계 구축
- 준공 · 인증 취득
### ▶ 설계자 액션
- 시공 감리 · 검측
- 준공 도서 검토
- 성능 확인 · 인수
### ◎ 협력 전문가
- 시공사
- 감리단
- O&M / 모니터링 업체
