## 검증된 도구 환경

```
python-pptx 1.0.2   openpyxl 3.1.5   pandoc 3.8.3
```

pptx는 전부 **16:9 (13.3 × 7.5 in)** 입니다. 새 덱도 이 크기를 유지하세요.

### ⚠️ 콘솔 인코딩 (cp949)

Windows 한국어 콘솔이라 python이 한글 출력 시 `UnicodeEncodeError: 'cp949' codec can't encode character`로 죽습니다. **python으로 pptx/xlsx를 다룰 때는 항상 UTF-8을 강제하세요:**

```bash
PYTHONIOENCODING=utf-8 python script.py
```

### ⚠️ `~$` 파일

`~$인증, 법규 기준.pptx`는 PowerPoint가 파일을 **열어둔 상태**임을 뜻하는 잠금 파일입니다. 읽지도, 지우지도, glob 결과에 넣지도 마세요 (`if f.startswith('~$'): continue`). 이 파일이 있으면 원본이 편집 중이므로 **덮어쓰기 금지** — 사용자에게 닫아달라고 요청하세요.
